# Marvel API

A Spring Boot API that handles register and login for users, creating, deleting reviews on the Marvel Universe Best Movies. 

## Purpose

Marvel API is created for the purpose to be the main API for the marvel-mobileapp. Which gives the mobileapp the **features** such as **register and login for users**, **creating reviews on movies**, **deleting reviews** and **deleting user account**.

> **Note:** This API is made for the marvel-mobileapp.

## Features

- GET reviews
- POST review/{id}
- DELETE review/{id}
- POST user/register
- DELETE user/{userId}
- PATCH review/{reviewId}
- GET review/{userId}
- GET movies/find
